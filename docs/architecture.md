## 3. Data flow and splits

| Split | Size | Use |
|---|---|---|
| train | 7,007 | ViT training only |
| val | 1,003 | 500 → **clean calibration set** (conformal scores AND drift reference — same set, per spec); 503 unused spare |
| test | 2,005 | **stream pool**: ~200 batches × 64, images drawn with reuse, corruption applied per batch |

The **deployed model** is the trained ViT plus temperature scaling fitted by NLL on the calibration set (standard deployment practice; restores the exposé's well-calibrated premise — memory.md D22). "Frozen classifier" below means ViT weights + fixed T.

Stream schedule (seeded): blocks of 10 batches share a regime drawn from {clean (~40% of blocks), (corruption ∈ {gaussian noise, gaussian blur, color jitter}) × severity ∈ {1,2,3}}. Block structure makes drift temporally correlated — realistic, and gives history-based policies something to exploit (disclosed in design.md §10). Every 10th batch is a **monitoring batch**: its labels are revealed to the policy *after* the action executes.

## 4. LangGraph node graph

Graph is invoked once per batch; persistent policy memory rides in the state object across invocations.

1. **SignalCollection** — forward pass through the *frozen* model (signals are always computed pre-intervention): embeddings (mean-pooled final-layer tokens), softmax probs, conformal sets under current frozen q_hat. Computes raw drift value and mean set size.
2. **RiskAssessment** — maps drift to a coarse bucket (3 buckets via clean-reference quantiles), set size to a band (normal/inflated → ACCEPT-gate), and assembles per-action expected net benefit `Q̂(a, bucket) − cost(a) (+ escalation info bonus)` from memory. All three exposé signals materialize here.
3. **PolicyDecision** — ε-greedy argmax over allowed actions; emits a human-readable reasoning string (signals, bucket, estimates, why this action) into the trace.
4. **Action** — executes:
   - ACCEPT: ship frozen predictions + conformal sets.
   - TTA: episodic LayerNorm adaptation (§6), ship adapted predictions + sets under the *recalibrated* threshold, then **revert**.
   - ABSTAIN: withhold all predictions for the batch (batch-level; per-sample is future work).
   - ESCALATE: withhold predictions, flag for human review, incur high fixed cost; ground-truth labels return to the policy.
5. **OutcomeLogging** — appends the JSONL record; if labels arrived (escalation or monitoring batch), computes realized per-action benefits (incl. counterfactual replay, design.md §6) and updates the outcome memory. Updates apply from the *next* batch onward (delayed feedback).

## 5. State schema

```python
class SupervisorState(TypedDict):
    # ---- transient, rebuilt each batch ----
    batch_id: int
    corruption: str            # logged for analysis; NEVER visible to the policy
    signals: {
        "drift_value": float,          # normalized mean-embedding distance to μ_ref
        "drift_bucket": int,           # 0/1/2 via clean-reference quantile edges
        "mean_set_size": float,        # frozen-model conformal sets
        "setsize_inflated": bool,      # > 1.5 × clean-reference mean set size
        "expected_net_benefit": {action: float},   # Q̂(a,b) − cost(a) (+bonus)
    }
    decision: {"action": str, "explored": bool, "reasoning": str}
    outcome: {                 # populated only when labels arrive (gated)
        "labels_source": "escalation" | "monitoring" | None,
        "ece_frozen": float, "ece_realized": float,
        "realized_benefit": {action: float},       # incl. counterfactuals
    }
    # ---- persistent across batches (the intervention memory) ----
    memory: {
        "estimates": {(action, bucket): {"mean_benefit": float, "n": int}},
        "labeled_count_per_bucket": {bucket: int},  # drives escalation info bonus
        "action_counts": {action: int},
        "last": {"action": str, "benefit": float | None},
    }
    q_hat_frozen: float        # conformal threshold for the frozen model (fixed after offline calibration)
```

Baselines reuse the same runner and trace format but replace PolicyDecision (and skip memory where not applicable).

## 6. TTA and adapt-then-recalibrate in the flow

**Episodic, always:** before adaptation, LayerNorm affine params (γ, β) are snapshotted; entropy minimization (mean per-sample softmax entropy, Adam lr=1e-3, 3 steps, LN params only) runs on the current batch; predictions are taken from the adapted model; then params are **restored** before the next batch. Continual TTA is future work and is why the exposé's non-stationarity argument is muted here (disclosed).

**Adapt-then-recalibrate:** while adapted, the frozen labeled calibration set (500 images) is rerun through the adapted model to recompute LAC scores and a fresh q_hat used *only* for this batch's prediction sets. This restores a fixed-score/fresh-quantile pairing but the calibration set is clean while the batch is shifted, so exchangeability is still not truly restored — flagged simplification, and exactly what RQ3 measures (coverage vs 95% with recalibration; an always-TTA-without-recalibration run supplies the contrast).

## 7. Evaluation harness vs policy information boundary

Two strictly separated label paths:
- **Policy learning**: labels only from escalated batches and monitoring batches, only post-decision (delayed, action-gated).
- **Metric reporting**: the harness uses full ground truth on all batches to compute the comparison table for every method (accuracy/ECE on issued predictions, coverage, net calibration benefit). This is standard and does not leak into decisions.
